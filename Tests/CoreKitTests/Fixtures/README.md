# CRM registry fixture

`registry-v1.json` is generated by the Core repository from
`src/lib/crm/registry` and copied from:

```text
core-web/fixtures/crm/registry-v1.json (sibling checkout)
```

Do not edit the JSON by hand. Refresh it with `scripts/sync-registry.sh`
after `pnpm crm:registry:generate` in Core (`--check` fails when the two
differ; `scripts/verify.sh` runs it). `CoreKitTests` must decode this fixture
before an iOS registry integration is considered compatible.
